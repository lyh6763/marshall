Front Row

무대 가까이의 열기를 느낀 뒤, 실제 제품을 바로 보고 탐색하는 Marshall 비공식 디자인 시안입니다. 분위기를 만드는 이미지와 제품을 설명하는 이미지의 역할을 다시 정리했습니다.

3실제 모델과 제품 사진
3상세 페이지 유지
4주요 화면 너비 검증
0가격·구매 기능

Problem

제품이 보이지 않는 제품 카드

이전 시안에서는 제품명 옆에 사용 장면을 배치했지만, 제품 자체의 외관은 알 수 없었습니다. 붉은 조명과 크림색을 반복하면서 새로운 구도도 기존 분위기에 머물렀습니다.

Direction

무대 다음에, 바로 제품

방문자가 콘셉트를 해석하기 전에 제품을 알아볼 수 있도록 홈의 순서를 단순하게 바꿨습니다.

  1. 가까운 관객 시점, 큰 타이포, 백색 조명의 무대 히어로
  2. 독립적인 선택 카드와 Signal Journey를 덜어내고 제품을 바로 배치
  3. DSL40 Combo를 크게 소개한 뒤 Acton IV와 Monitor III A.N.C.를 나란히 소개
  4. 추천 질문과 서로 다른 장비군의 비교 체크박스를 제거하고 상세 링크 제공
  5. 제작·작은 공연장·Amplify 이야기를 간결한 공식 자료 링크로 제공

Images

현장과 제품, 각각의 이미지

히어로는 익명 연주자의 가상 공연 장면을 내장 ImageGen으로 제작했습니다. 백색 조명과 자연스러운 피부·옷감의 질감으로 기존의 붉은 조명과 따뜻한 색 보정을 벗어나도록 시도했습니다. 제품 영역은 공식 페이지의 실제 모델 사진을 사용했습니다.

공식 사진은 사용자가 승인한 로컬 검토용 시안에 사용했습니다. 이 시안을 공개 배포하지 않았으며, 공식 사진의 공개 사용 허락을 받았다는 뜻은 아닙니다.

Verification

현재 확인한 동작

Edge에서 390·768·1440·1920px 홈 화면과 390·1440px 상세 페이지를 확인했습니다. 홈 화면의 이미지 누락, 가로 넘침, 페이지 스크립트 오류는 없었습니다.

  1. 모바일 메뉴의 Enter 열기, Tab 순환, Escape 닫기와 포커스 복귀
  2. 앰프 앵커의 고정 헤더 간격과 세 제품 상세·목록 복귀 경로
  3. 모션 감소에서 히어로 이동 제거
  4. JavaScript 비활성 상태에서 메뉴와 제품 상세 이동
  5. 모바일과 데스크톱에서 해당 히어로 이미지 한 개만 요청

npm test 통과. 실제 사용자 테스트와 배포 후 Core Web Vitals 실측은 아직 수행하지 않았습니다.
