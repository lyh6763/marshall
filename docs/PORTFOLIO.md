# Marshall Front Row 포트폴리오 요약

## 문제

이전 시안은 무대 분위기를 제품 영역까지 반복하면서 정작 제품 외관을 보여주지 못했다. 장면 선택·추천·비교 등 여러 단계가 세 모델의 직접 탐색보다 앞에 놓였다. 붉은 조명과 크림색이 반복되어 디자인 변화도 작게 느껴졌다.

## 현재 해결

- 첫 화면의 근접 공연 구도와 큰 타이포는 유지하되 백색 조명·중성색으로 변경.
- 제품 영역에는 실제 DSL40 Combo / Acton IV / Monitor III A.N.C. 사진 사용.
- 별도 경로 선택·추천 질문·비교표를 덜어내고 제품과 상세 링크를 바로 제공.
- 공식 사양·사용 장면·비적합 상황·출처는 기존 상세 URL에 유지.
- 이야기는 제작·작은 공연장·Amplify 공식 자료로 직접 연결.

## 구현·검증과 한계

정적 HTML·CSS·Vanilla JS. npm test와 Edge 렌더링으로 390/768/1440/1920px 홈, 390/1440px 상세, 모바일 키보드 메뉴, 모션 감소, JavaScript 비활성 경로를 검증했다. 실제 사용자 테스트와 배포 후 Core Web Vitals는 미측정이다.

히어로는 가상 공연 생성 이미지다. 공식 제품 사진은 사용자가 승인한 로컬 비공개 시안에만 사용하며 공개 배포 이용허락을 뜻하지 않는다. 브랜드 운영과 무관한 독립 포트폴리오다.
