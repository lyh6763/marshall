# MARSHALL 포트폴리오 요약

## 1. 프로젝트 정보
- 프로젝트명: MARSHALL
- 유형: 개인 포트폴리오 리디자인 프로젝트
- 기간: 2025.12 제작 / 2026.02, 2026.04, 2026.05 품질 개선
- 역할: 원페이지 UX 흐름 및 정보 구조 설계, 반응형 UI 퍼블리싱, Vanilla JS 인터랙션 구현, 접근성/성능/레이아웃 QA 개선
- 산출물: 원페이지 웹사이트

## 2. 목표/의도
- 브랜드 스토리 중심의 원페이지 흐름 구성
- 섹션별 강한 타이포/카피로 톤 전달

## 3. 30초 소개
Marshall의 강한 록 헤리티지와 제품/아티스트/커뮤니티 콘텐츠를 하나의 스토리 흐름으로 재구성한 원페이지 리디자인입니다. 단순한 시각 재현보다 모바일 탐색, 접근성 상태 동기화, 콘텐츠 이미지 최적화까지 함께 다듬어 포트폴리오 평가자가 퍼블리싱 완성도와 개선 과정을 함께 확인할 수 있도록 만들었습니다.

## 4. 기술 어필 포인트
- `IntersectionObserver`로 스크롤 애니메이션을 화면 진입 시점에만 실행하고, 1회성 애니메이션은 관찰을 해제해 불필요한 콜백을 줄였다.
- 모바일 메뉴는 body scroll lock, ESC 닫기, Focus Trap, 포커스 복귀를 적용해 키보드 사용 흐름을 안정화했다.
- 푸터 아코디언은 `aria-expanded`, `aria-hidden`, `tabindex`를 동기화해 보이지 않는 링크가 탭 순서에 남지 않도록 했다.
- 반복 CTA에는 목적별 `aria-label`을 추가하고, placeholder 링크는 실제 공식 콘텐츠 URL로 교체했다.
- 의미 있는 이미지는 CSS background에서 `picture/img`로 옮기고 alt, dimensions, lazy loading, srcset/sizes, WebP/AVIF를 적용했다.

## 5. 정보 구조
- About → Products → Artists → Social 순서의 스토리텔링 구조
- Social 섹션 내 슬라이더로 다양한 콘텐츠 노출

## 6. 주요 기능
- 모바일 메뉴 오버레이 + 접근성 대응
- 스크롤 애니메이션(IntersectionObserver)
- Swiper 슬라이더
- 실제 목적지로 연결되는 CTA/푸터/소셜 링크
- alt, lazy loading, srcset/sizes, WebP/AVIF를 적용한 콘텐츠 이미지

## 7. 기술 스택
- HTML5 / CSS3 / Vanilla JS
- Swiper

## 8. 검증 결과
- PR 브랜치 기준으로 오타/placeholder/mojibake 흔적, 누락 이미지 참조, 외부 링크 `target/rel`, 이미지 `alt/width/height`, CSS brace 균형을 점검했다.
- Chrome headless에서 모바일/태블릿/데스크톱 렌더링, 메뉴 접근성 동작, 콘텐츠 이미지 로드, AVIF 선택, 콘솔 오류 여부를 확인했다.

## 9. 결과/배운 점
- 브랜드의 강한 이미지를 유지하면서도 About → Products → Artists → Social로 이어지는 명확한 원페이지 흐름을 구성했다.
- 모바일 메뉴, 푸터 아코디언, 스크롤 애니메이션, 슬라이더를 모듈 단위로 분리해 유지보수성을 높였다.
- 과한 hover 효과를 덜어내고 제품 이미지와 텍스트 비율을 정리하면서 브랜드 톤에 맞는 절제된 인터랙션의 중요성을 확인했다.
- 임시 링크와 CSS background 이미지를 정리하면서 접근성, 성능, 콘텐츠 의미가 HTML 구조에서 함께 드러나도록 개선했다.
- 반응형 검증 과정에서 이미지 크기, 텍스트 줄바꿈, 섹션 간 여백 리듬이 전체 완성도에 큰 영향을 준다는 점을 학습했다.

- 키보드/스크린리더 테스트 범위를 넓힌 접근성 검증 강화
- Social/Artists 섹션의 콘텐츠 데이터를 확장해 더 풍부한 브랜드 경험 제공
