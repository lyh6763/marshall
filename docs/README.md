# Marshall Front Row

Marshall의 무대 에너지를 재해석한 비공식 독립 포트폴리오 시안입니다. 실제 Marshall 사이트나 판매 채널이 아닙니다.

## 현재 경험

- 가까운 관객 시점의 공연 히어로와 직접적인 제품 카테고리 메뉴.
- DSL40 Combo → Acton IV / Monitor III A.N.C. 순서로 실제 제품 사진과 상세 링크 제공.
- 상세 페이지에 공식 사양·비적합 상황·출처·확인일 표시.
- 앰프 제작·작은 공연장·Amplify 공식 자료로 바로 이동.
- 공식 제품 사진은 사용자 승인에 따른 로컬 비공개 검토용입니다. 공개 배포 이용허락은 확보하지 않았습니다.

## 기술과 확인

HTML·CSS·Vanilla JS. 기본 검사: `npm test`. 로컬 서버 예시: `npx serve -l 4321 .`.

390/768/1440/1920px 홈, 390/1440px 상세, 모바일 키보드 메뉴, 모션 감소, JavaScript 비활성 경로를 확인했습니다. 실측 전 성능 향상 수치는 제시하지 않습니다.
