## 비주얼

현재 히어로는 `front-row-white.webp`와 `front-row-white-mobile.webp`다. 익명의 가상 기타리스트를 가까운 관객 시점에서 바라보는 장면을 ImageGen으로 제작했다. 실존 아티스트나 실제 공연 기록이 아니다. 제작 프롬프트는 [현재 제작 기록](REFRESH_STUDY.md)에 보관한다.

제품 카드와 상세 페이지는 위 공식 제품 페이지의 실제 모델 사진을 사용한다. 사용자는 2026-09-29 **로컬 시안에 공식 제품 사진 사용**을 승인했다. 출처 이미지는 크기·형식만 최적화했으며 제품 외관을 생성하거나 변경하지 않았다. 원본 URL은 [제품 이미지 매니페스트](product-image-sources.json)에 기록했다. 이 승인은 공식 권리자의 공개 배포 허락을 뜻하지 않는다. 배포 전 별도 확인이 필요하다.

이전 `scene-personal`, `scene-room`, `scene-stage` 장면과 붉은 조명의 `front-row-hero`는 파일만 보존하며 현재 화면에는 사용하지 않는다. 이야기 영역은 사진이나 인물 대신 주제와 일치하는 공식 자료 텍스트 링크를 제공한다.
