## 비주얼

현재 히어로는 `front-row-white.webp`와 `front-row-white-mobile.webp`다. 익명의 가상 기타리스트를 가까운 관객 시점에서 바라보는 장면을 ImageGen으로 제작했다. 실존 아티스트나 실제 공연 기록이 아니다. 제작 프롬프트는 [현재 제작 기록](REFRESH_STUDY.md)에 보관한다.

제품 카드·상세 페이지·Case Study의 제품 이미지는 직접 그린 SVG 일러스트(`img/illust-combo-amp.svg`, `illust-home-speaker.svg`, `illust-headphones.svg`)다. 형태만 단순화했고 Marshall 로고와 브랜드 고유의 외관 요소(금색 패널 등)는 넣지 않았다. 실제 제품과 세부가 다르다는 안내를 상세 페이지 출처 문구에 함께 적었다.

이전 단계(2026-09-29~10-06)에는 사용자 승인에 따라 공식 제품 사진을 로컬 검토용으로 썼고, 공개 배포 이용허락이 없어 2026-10-07 자체 일러스트로 교체했다. 당시 원본 URL은 [제품 이미지 매니페스트](product-image-sources.json)에 기록으로 남긴다.

이전 `scene-personal`, `scene-room`, `scene-stage` 장면과 붉은 조명의 `front-row-hero`는 2026-09-30 저장소에서 제거했다(비공개 작업 저장소에 보관). 이야기 영역은 사진이나 인물 대신 주제와 일치하는 공식 자료 텍스트 링크를 제공한다.
